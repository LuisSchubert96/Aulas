<h1>📚 Aprendizado em JavaScript</h1><br>

Este repositório foi criado para documentar minha jornada de aprendizado em JavaScript. Aqui, compartilho códigos, exercícios e projetos desenvolvidos durante meus estudos.

<h2>✨ Objetivo</h2><br>

Explorar os conceitos fundamentais e avançados de JavaScript, aplicando-os em exemplos práticos para reforçar o conhecimento.

<h2>📌 Conteúdo</h2><br>

O repositório está organizado por tópicos, abordando diferentes aspectos do JavaScript:

🔹 Variáveis: Declaração, tipos de dados e escopo<br>

🔹 Comparadores: Operadores de comparação e lógicos<br>

🔹 Condicionais: if, else, else if, switch-case<br>

🔹 Loops: Estruturas de repetição como while<br>

🔹 Funções: Declaração, parâmetros, retorno e boas práticas<br>

🔹 Objetos e Arrays: Estruturas de dados, manipulação e métodos<br>

<h2>🚀 Como Utilizar</h2><br>

Clone este repositório:<br>

git clone https://github.com/LuisSchubert96/JavaScript.git<br>

Acesse a pasta do projeto:<br>

cd JavaScript<br>

Explore os arquivos e práticas correspondentes aos tópicos de aprendizado.
